# VidgetYo

Небольшой виджет задач для рабочего стола macOS. Работает с [Ёжкой](https://yozhka.lukit.ru/): один раз входите, выбираете пространство и доску — дальше список живёт поверх всех окон.

В меню-баре иконка с чеклистом. Окно видно на всех рабочих столах; обычные приложения его перекрывают, если не включить «Поверх окон» в настройках. Тянуть можно за свободное место на карточке.

## Первый запуск

1. Соберите в Xcode (`VidgetYo.xcodeproj` → Run - локальная сборка) или скачайте `.dmg` из [Releases](https://github.com/ZeppelinOFF/vidgetYo/releases).
2. Введите почту и пароль от Ёжки — **пароль нигде не сохраняется**, сессия лежит в Keychain.
3. Выберите пространство и доску.

В виджете можно отмечать задачи выполненными, добавлять новые и открывать карточку в браузере.

В настройках — проверка обновлений с GitHub: если вышла новая сборка, можно скачать DMG под ваш Mac (Apple Silicon или Intel).

## Сборка DMG

Нужен Xcode 27:

```bash
./scripts/build-installer.sh
```

Файлы появятся в `dist/`. Без платной подписи Apple macOS может попросить открыть приложение через Control‑click → «Открыть».

## Для разработчиков

Тесты: `./scripts/test.sh`.

Пуш в `main` поднимает версию по тексту коммита (`major` / `minor` / иначе patch), собирает DMG и выкладывает релиз на GitHub.
