# VidgetYo

Виджет задач на рабочем столе macOS. Он подключается только к [Ёжке](https://yozhka.lukit.ru/): при первом запуске спрашивает почту и пароль, затем пространство и доску.

Иконка в меню-баре — чеклист. Окно лежит на обоях и на всех рабочих столах. Обычные окна его закрывают; пункт «Поверх окон» поднимает его над ними. Перетаскивание — за пустое место карточки.

## Запуск

Откройте `VidgetYo.xcodeproj` и нажмите Run.

Либо из терминала:

```bash
xcodebuild -project VidgetYo.xcodeproj -scheme VidgetYo -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/VidgetYo.app
```

При первом запуске откроется окно входа. Почта и пароль — те же, что на сайте. Пароль не сохраняется: остаются токены сессии. После входа выберите пространство, затем доску (проект Ёжки). Виджет показывает задачи этой доски, отмечает выполнение и создаёт новые.

## Пакет

На Mac с Xcode 27:

```bash
./scripts/build-installer.sh
```

Готовые образы: `dist/VidgetYo-<версия>-macOS27-arm64.dmg` для Apple Silicon и `dist/VidgetYo-<версия>-macOS27-x86_64.dmg` для Intel. Одна архитектура: `ARCH=arm64 ./scripts/build-installer.sh` или `ARCH=x86_64 ./scripts/build-installer.sh`. Сборка Release. Без Developer ID подпись ad-hoc: при первом запуске может понадобиться Control-click по приложению и «Открыть».

## Версии

В `MARKETING_VERSION` лежит последняя выпущенная версия, формат `major.minor.patch`.

Пуш в `main` запускает Action: по сообщениям коммитов версия поднимается, собирается DMG и публикуется GitHub Release `vX.Y.Z`.

- `major` в сообщении коммита поднимает первую цифру
- `minor` поднимает вторую
- любое другое сообщение поднимает третью

Коммит с поднятой версией бот пушит сам и помечает `[skip ci]`, чтобы сборка не зациклилась. Сейчас в проекте `0.1.0`, первый пуш в `main` выпустит `0.1.1`.
